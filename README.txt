Build the Android app (APK):
1) Install Android Studio (https://developer.android.com/studio)
2) File > Open... and choose this folder. Wait for Gradle sync (internet needed the first time).
3) Build > Build Bundle(s) / APK(s) > Build APK(s)
   The APK is created in app/build/outputs/apk/debug/app-debug.apk
4) Copy it to your phone and install (allow "Install unknown apps"),
   or connect the phone with USB debugging and press Run.
For Google Play: Build > Generate Signed Bundle / APK > Android App Bundle.
The game page is app/src/main/assets/index.html. Store icon: play-store-icon-512.png
